# One Live Build — present an eco-city project

Use the pinned origin in `ECO-CITY-BUILD-LINKS-2026-10-19.md`. `/pitch/eco-city` and `/pitch/construction` open the same guided presentation. The app, dashboard and other pitch links are in that directory too.

## Personalise before a meeting

1. Open **Personalise**. Enter the prospect's public company name and a public project title.
2. Choose Developer, Construction team, Public / infrastructure team, or Merchant / supplier. Choose an eco neighbourhood, apartment development or mixed-use district.
3. Pick Sage, Ocean or Graphite; press **Done**.
4. In **Your pilot**, use **Share this version** to copy the URL. Company, project, audience, scenario and theme travel with that link. Unknown parameters are not forwarded.
5. **Download presentation brief** saves a JSON record of the presentation settings and scope. It is a brief, not a build model, price quotation or procurement instruction. Booking opens the existing one-hour Calendly meeting page; no meeting is booked automatically.

Keep confidential details out of these public labels. This release customises presentation labels and scenarios; it does not load a client's private project into the pitch.

## A concise walkthrough

- **The whole build:** start with one property connected to district infrastructure. The picture is a capture of the actual City workspace.
- **Tools in context:** select each of the five workstreams. Explain the measured input, resulting quantities and review boundary. Cover walls/openings/floors/roofs; foundations/materials; plumbing/electrical/HVAC/fire; roads/utilities/energy; gardens/pools/interiors.
- **One project:** choose a stakeholder, then **Rehearse a design change**. All six stations display the same new example revision with a different responsibility. Explain that the pitch rehearsal is local; the shared cloud project requires activation.
- **Logistics:** move across Design → Quantities → Review → Supplier → Schedule → Site → Handover. Each step names its input, output, owner and release check. Dates and email recipients are records to coordinate; recording them does not send a purchase order or invoice.
- **Eco + AI:** compare carbon, tropical climate and local/import evidence. Run the labelled scripted AI example to show Brief → Propose → Review → Approve separately. In the real app, hosted AI needs a configured service. Neither interface gives engineering certification.
- **Real products:** show the actual in-app Courts Comfy and Espace Seville representations. Open their merchant sources to discuss exact supply. Scale is sourced; appearance is illustrative until approved manufacturer assets are supplied.
- **Your pilot:** agree a bounded site, nominated roles, a few source-backed components and a release review. Save the brief and book a walkthrough.

The guided construction/eco-city pitch exposes no full design editor. The separate main app and other legacy decks retain their own demos. On phone, swipe the chapter strip and scroll within a chapter for detail. Arrow keys/Home/End operate focused chapter tabs.

## Demonstrate the working dashboard separately

1. Open `/demo?panel=shared&pitch=1`. Its **Local pilot · this browser** label is deliberate.
2. Choose **Team & logistics**. Select a handoff step to see the owner, state and unresolved checks, then open its contextual review.
3. Switch among Developer / project lead, Architect, Engineer, Supplier, Contractor and Client to see different action queues. Role rehearsal is not authentication. The real connected mode uses project membership and server permissions.
4. Select a component, assign responsibility and a proposed delivery date, and save its note. An unassigned supplier sees an assignment prompt rather than all private packages.
5. Return to City, create the eco-district example and edit a measured road dimension. Return to Shared project to review the changed quantities and stale review state. The linked detailed house is counted once.
6. **Export team handoff** downloads the current revision, component register and separate delivery references. Quantities with different units are never added into one number.

Cloud migration0032, authenticated multi-account acceptance and supplier/email integrations remain outside this preview release. No threaded chat, guaranteed automatic procurement or simultaneous geometry co-editing is promised.
