## Deliberate boundaries and remaining work

- Long pitch storytelling, employee handbook content, product descriptions and some Studio prose remain English. Chapter menus/actions are translated; the entire presentation text is not yet translated.
- Some detailed legacy Materials, Foundation, Plumbing/Electric, AI, import, shopping and merchant-administration panels still contain English labels, tooltips, validations or explanations. The shared close/floor/navigation controls are translated, not every nested legacy field.
- Engineering findings retain original evidence labels, assumptions, missing-data descriptions and source titles. All 27 finding headings and static recommendations are translated. Three recommendations are generated by detailed validation (`foundation-invalid`, `materials-incomplete`, `service-disconnected`); their exact original text is preserved so translation cannot conceal identifiers, dimensions or the actual problem. Unknown future rules fall back to their original engine text.
- Browser-native date/number control formatting can differ by browser. Machine payloads, saved values, SI units, geometry, prices, calculation ratios and source references are not converted by the language setting.
- This layer does not translate arbitrary DOM nodes or user data. Add actual React translation calls and four complete dictionary values when extending a screen. A future rule should add its display translation; the rule-coverage test fails if a stable engine ID is omitted.
- Language/theme preferences are per device/browser origin, not a cloud user-profile feature.
